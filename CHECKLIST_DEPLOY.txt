🔧 EM CASO DE PROBLEMAS
═══════════════════════════════════════════════════════════════════════════════
  Erro 404 "Página não encontrada"
    → Verifique se index.html existe em public_html/

  Página em branco ou erros no console
    → Abra DevTools (F12) e veja os erros específicos
    → Verifique se os caminhos dos arquivos estão corretos

  CSS/JavaScript não carregam
    → Confirme que a pasta static/ existe no mesmo nível de index.html
    → Verifique permissões de arquivo (755 para pastas, 644 para arquivos)

  Não consigo conectar FTP
    → Verifique credenciais em cPanel > FTP Accounts
    → Tente SFTP em vez de FTP (mais seguro)

  Domínio não aponta para os arquivos
    → Aguarde propagação DNS (até 24h)
    → Verifique apontamento em cPanel > Domains
